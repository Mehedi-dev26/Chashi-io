# BWA Smart Irrigation

আমি একটি এমন সিস্টেম তৈরি করতে চাচ্ছি যেই সিস্টেমটি হলো যে, আমাদের বাংলাদেশে যে uh BWA অর্থাৎ যে বরেন্দ্র বহুমুখী উন্নয়ন প্রকল্পের যে সেচ havent প্রকল্প টি আছে, তো আমি এটিকে আরও advance এবং unique level এ নিয়ে যেতে চাচ্ছি। যেমন হচ্ছে এই project টি আমি IoT project system একটি based system তৈরি করতে চাচ্ছি। যেখানে প্রত্যেকটি আ তোমার আ জমির পানির level এবং কোন জমিতে পানি যাবে সেগুলো আমি mobile phone এবং আমার laptop এর আমার একটি system এর মাধ্যমে সবকিছু control করতে চাচ্ছি এবং আমার যে মোটর on off থেকে শুরু করে সবকিছু পুরো system টি আমি আ একটি professional ভাবে যেকোনো জায়গা থেকে manage করতে পারি, এরকম একটি আ online system build up করতে চাচ্ছি। আ তো দেখা যাচ্ছে যে আমার main মোটরটি on হলো এবং কোন দিকে যাবে পানির লাইন নির্ধারণ থেকে সমস্ত কিছু আমি করতে পারি। আ visual map থেকে শুরু করে একদম professional একটি dashboard থাকবে যেটি mobile responsive, desktop responsive হবে। তো এইরকম একটি application আমি design করব যেটি আমি IoT project based webhook, HTTP server যাবতীয় ব্যবহার করে আমি পরবর্তীতে সেগুলো setup করতে পারবো। তো আমি শুধু আপাতত dashboard এবং যাবতীয় functionality সবকিছু চাচ্ছি এবং সেটি AI based হবে, যাবতীয় সমস্ত কিছু।
